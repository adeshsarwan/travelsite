# GoWandria

Static prototype for gowandria.com.

## V1 scope

- Warm, colorful travel-discovery homepage
- Destination pages for Bali, Cancun, Miami, London and Goa
- Lightweight static trip matcher
- No database
- No external travel APIs
- No monetization

Everything is intentionally static so the visual experience and content structure can be reviewed before introducing a destination database or live travel inventory.
